## 1. 핵심 루프

```
B1 외곽 (20명 동시 출발)
   │  미로를 뚫고 중심으로
   ▼
B1 중심 투하구  ──낙하──►  B2 외곽
   │
   ▼          … 8층 반복 …
   ▼
B8 중심 = 도착점.  먼저 닿은 한 명이 이긴다.
```

**층마다 외곽에서 중심으로.** 투하구는 언제나 중심에 있고, 떨어지면 언제나 다음 층
*외곽*에 선다. 그래서 층을 내려갈 때마다 미로를 처음부터 다시 푼다 — 여덟 번.

### 왜 외곽에 떨어지는가

투하구가 중심에 있는데 착지도 중심이면, 한 번 중심에 닿은 사람은 그대로 여덟 층을
떨어져 끝난다. 미로가 한 번밖에 없는 게임이 된다. 착지점을 외곽으로 보내야 **각 층이
독립된 미로**가 되고, 그때 비로소 "미로 탈출을 여덟 번" 이라는 형태가 성립한다.

중심의 투하구는 **2~3개**다. 어느 것으로 뛰어내리느냐가 아래층 어디에서 시작하느냐를
정한다 — 무작위가 아니라 고정된 대응이므로, 맵을 아는 사람이 유리하다. 그것이 이
게임의 실력이다.

## 2. 중심으로 가는 길은 왜 어려운가

이게 이 기획의 전부다. **거리로 어렵게 만들면 지루하고, 좁혀서 어렵게 만들면 경주가
된다.** 네 개의 레버를 쓴다.

### ① 동심 3겹 — 관문이 줄어든다

```
        외곽 고리   ← 20명이 여기서 시작한다.  넓고, 밝고, 안전하다.
          ↓ 관문 4개
        중간 고리   ← 붐빈다.  여기서 순위가 갈리기 시작한다.
          ↓ 관문 2개
        안쪽 고리   ← 좁다.  마주치면 피할 수 없다.
          ↓ 관문 1개
         중심 투하구
```

들어갈수록 문이 줄어든다. **마지막 관문은 하나**여서, 그 층의 20명이 전부 같은 한 칸을
지나야 한다.

### ② 문 — 남을 막을 수 있다

§12의 잠글 수 있는 문은 이미 구현돼 있다 (`DoorState` · `DoorInteractable`).
협동 게임에서 이 문은 *괴물*을 막는 물건이었다. 경주에서는 **뒤따라오는 사람**을 막는
물건이 된다.

- 닫는 데 1.1초 — 그동안 당신은 멈춰 있고, 뒤에서 오는 사람은 달리고 있다
- 부수는 데 4.5초 — 닫고 도망치면 3.4초를 번다
- **부서진 문은 다시 닫히지 않는다** — 선두가 쓴 문은 그 뒤 사람들에게는 없는 물건이다

이 세 줄이 그대로 경주 규칙이 된다. 숫자를 하나도 바꿀 필요가 없다.

### ③ 괴물은 안쪽을 순찰한다

§07의 순찰 반경을 **고리 단위**로 다시 쓴다. 괴물은 중심에서 시작해 안쪽 두 고리를
돈다. 외곽은 안전하고 중심은 위험하다 — 그래서 1등을 하려면 위험을 통과해야 하고,
안전하게 가면 진다.

죽으면 탈락이므로, 경주에서 괴물은 *공포*이자 *탈락 조건*이다. 협동판보다 더 무섭다.
그때는 팀이 부활시켜 줄 수 있었지만 지금은 그걸로 끝이다.

### ④ 안쪽일수록 어둡다

§03의 어둠 규칙을 고리에 건다. 외곽 고리는 상시 조명, 중간 고리는 꺼져 있고, 안쪽
고리는 손전등 사거리 바깥이 보이지 않는다. 배터리(§08의 소모 규칙)는 그대로 살아서,
**빨리 갈수록 배터리를 아낀다**는 압박이 된다.

## 3. 살아남는 것 / 버리는 것

### 살아남는다 — 지금까지 만든 것의 대부분

| 시스템 | 경주에서의 역할 |
|---|---|
| §05 이동 (걷기 2.0 · 달리기 4.5 · 질주 5.6) | 그대로. 경주의 기본 단위 |
| §06 괴물 — 상태 기계 · 덮치기 · 발소리 청취 | 그대로. 탈락 위험이 됨 |
| §07 시간 위협도 | 그대로. 늦게 갈수록 괴물이 빨라진다 = 지각자 처벌 |
| §09 유령 | **탈락자 관전**. 이미 만들어져 있다 |
| §12 문 | **경주의 핵심 상호작용** |
| 바닥 재질 8종 · 발소리 · 폐색 | 그대로. 남의 위치를 소리로 안다 |
| 어둠 · 손전등 · 배터리 · 조명탄 | 그대로. 고리별로 배치만 다시 |
| §10 그늘 | 그대로 |

### 버린다

| 시스템 | 이유 |
|---|---|
| §01 왕복 · 지상 상점 | 경주에 재보급이 없다 |
| §02 승패 조건 전체 | 다시 쓴다 |
| §03 단서 3층위 (층→구역→지점) | 목적지가 처음부터 알려져 있다: 아래 |
| §08 전리품 · 크레딧 · 판매 | 통화가 없다 |
| 목표물 회수 · 호송 | 없다 |

### 바뀐다

**§04 5개 직업 → 전부 삭제.** 20명이 완전히 같은 몸으로 출발한다.

능력을 나눠 주면 경주의 결과가 **픽으로 설명된다.** 진 사람은 자기 선택이 아니라 자기
픽에서 이유를 찾고, 그러면 다음 판에 고칠 것이 없다. 그리고 픽이 있으면 최적 픽이
생겨서, 20명 중 열여덟이 같은 것을 고르는 순간 선택은 사라지고 밸런싱만 남는다.
없애는 것이 균형을 맞추는 것보다 확실하다.

**전원이 갖는 것:** 손전등(유한 배터리) · 문 · 질주 5.6 m/s(체력 제한) · 귀.

질주만은 반드시 남아야 한다. 괴물의 덮치기는 **달리는 사람(4.5)은 잡고 질주하는
사람(5.6)은 놓치도록** 맞춰져 있어서, 질주가 없으면 걸린 순간 누구도 살 수 없고
§12의 시야 차단 지형이 통째로 무의미해진다. 유한하게 만들어 **"지금 쓸까, 마지막
관문에서 쓸까"**를 이 게임의 핵심 결정으로 삼는다.

버려지는 코드: `RoleId` 분기, 직업별 능력 5종, 직업 선택 UI. 능력 중 **문**과
**구역 조명**은 전원 공용으로 승격하고, 나머지(청음 표시 · 괴물 시야 표시 · 섬광)는
제거한다.

## 5. 캐릭터

20명을 **한눈에 구분할 수 있어야 한다.** 지금은 플레이어 모델이 하나이고 직업 색만
다르다. 20명이 같은 복도에 있으면 누가 누군지 모른다.

`tools/blender/gen_player_model.py`는 이미 파라메트릭이다. 시드 기반 **캐릭터 생성기**로
바꾼다:

- 키 · 체격 · 어깨 폭 (실루엣이 먼저 구분돼야 한다 — 어두운 복도에서는 색이 안 보인다)
- 머리/장비: 방독면 · 헬멧 · 두건 · 맨머리
- 코트 길이 · 장비 벨트
- 색: 어두운 곳에서도 구분되는 20색 팔레트
- 이름표 — 근거리에서만 보이는

**실루엣 우선**이 원칙이다. §03이 만드는 어둠 속에서 색은 사라지고 윤곽만 남는다.

## 6. 맵 — 다시 그려야 한다

지금 8개 층은 전부 **계단이 가장자리에 있는** 구조다. 새 기획과 정반대다.
`MapSketch`의 방사형 저작이 필요하다:

- `RadialStorey` — 외곽/중간/안쪽 고리와 관문 수를 받아 층을 생성
- 중심에 투하구 2~3개, 각각 아래층 외곽의 정해진 착지점으로
- `MapValidator`에 새 규칙: 고리별 관문 수, 중심까지의 최단 경로 길이 밴드,
  마지막 관문이 정확히 하나일 것

§12의 기존 규칙 중 살아남는 것: 20 m 직선 상한, S자 통로, 순환로, 막힌 길 20~25%,
구역 대각선, 구역당 바닥 재질 1개. 이것들은 미로가 미로이기 위한 규칙이라 경주에서도
그대로 유효하다.

## 8. 지금 막고 있는 것

전환과 무관하게 이미 걸려 있는 문제 하나가 있고, 새 기획에서는 **더 치명적**이다.

`MapPipeline`이 8층 씬 쓰기를 거부했다: NavMesh가 6조각으로 갈라지고 괴물이 28개
후보 지점 중 **0개**에 닿는다. 원인은 계단통 메시의 중간 참(B-001) — 다섯 층까지는
견뎠는데 여덟 층 15개 계단에서 무너졌다.

새 기획은 **층 이동이 게임의 전부**다. 투하구를 만들기 전에 이걸 해결해야 한다.
다행히 방사형으로 다시 그리면 계단통 자체가 사라지고 투하구로 바뀌므로, B-001은
고치는 대신 **없어질** 가능성이 높다. 투하구를 먼저 만들고 다시 측정한다.
