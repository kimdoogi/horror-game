# ============================================================================
# 하강 — DESCENT-PIVOT §3 「버린다」가 지운 어휘.
#
# WHY THIS IS A DATA FILE AND NOT A C# ARRAY
# ------------------------------------------------------------------------
# Two instruments read it, and they cannot share code:
#
#   * Assets/Tests/EditMode/Pivot/PivotTombstoneTests.cs — reflects over every
#     assembly the player build ships, plus PivotAssetTombstoneTests.cs which
#     walks Assets/ for scenes, prefabs, .asset files and audio clips. Runs
#     inside the editor, so it takes Unity's project lock.
#   * core/HorrorGame.Core.Tests/PivotDeletionTests.cs — sees only
#     HorrorGame.Core, but runs in two seconds with no editor and no lock, so
#     it is the one that actually runs on every change.
#
# Unity compiles nothing outside Assets/ and the dotnet solution references
# nothing inside it, so the two guards each carry their own copy of the
# tokeniser. That duplication is deliberate and it is self-detecting: the
# `token|` and `probe|` rows at the bottom of this file are executed by BOTH
# implementations, so a tokeniser that drifts turns its own side red.
#
# WHAT THIS FILE IS NOT
# ------------------------------------------------------------------------
# It is NOT a roll of the 72 members that survived the last pivot. Such a list
# is green the day it is written and stale a month later. These are the *nouns*
# of the deleted designs, and they go stale only when the design does.
#
# It is NOT a substring list. Every reader tokenises identifiers first —
# 「advance」 does not contain 「van」, 「include」 does not contain 「clue」,
# 「SortOrderPanel」 is not a 배전반. See the `probe|` rows: those three are in
# there because this repository has already cried wolf on all three.
#
# FORMAT
# ------------------------------------------------------------------------
#   solo|word|section|reason
#       The token alone is proof. Matched whole, never as a substring.
#   compound|word|mate mate mate|section|reason
#       The token is ambiguous on its own. It counts only when one of the
#       mates appears beside it in the same identifier, or in the name of the
#       type / file that declares it.
#   korean|noun|section|reason
#       Hangul has no case and no word boundary inside an identifier, so these
#       are matched by containment within a Hangul run. Each one is checked
#       against the `race|` rows so it cannot swallow a word the race needs.
#   race|noun
#       Vocabulary the race DOES need. No race noun may CONTAIN a korean| noun —
#       that is the direction that produces a false alarm. The reverse nesting is
#       harmless and there is one on purpose: 목표물 ⊃ 목표, and the matcher looks
#       for 목표물 inside the text, so a scene saying 목표 지점 does not fire.
#   token|input|expected tokens
#       Pins the tokeniser itself.
#   probe|identifier|expected words or -|why this probe exists
#       Pins the matcher over an identifier, in code.
#   assetprobe|raw text run|expected words or -|why this probe exists
#       Pins the matcher over a run of text lifted out of asset YAML, where an
#       extra rule applies: a run beginning `m_` is Unity's own serialised key
#       and is skipped. Our own serialised fields are `_`-prefixed.
#
# ADDING A WORD
# ------------------------------------------------------------------------
# The reason field is the test. If you cannot finish the sentence "the race
# does not need this because ...", the word does not belong here. If you are
# here because a guard is red, the question is not "how do I make it pass" but
# "what did I just add to a 선착순 미로탈출게임 that has no currency, no search
# and nothing to carry".
# ============================================================================
